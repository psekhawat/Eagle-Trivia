# Philadelphia Eagles Daily Trivia 🦅

An interactive, Wordle-style daily trivia web application dedicated to the Philadelphia Eagles. Built with Tailwind CSS, custom Midnight Green & Silver branding, responsive mobile design, and a seeded daily rotation of over 225 questions.

## Features
- **Once-a-Day Challenge:** Players get one question per calendar day that locks after answering until midnight.
- **Seeded Daily Randomization:** Every player worldwide gets the same shuffled question each day without repeats across a 225-day cycle.
- **Spoiler-Free Sharing:** Easily share your streak and score status (`🟢` / `🔴`) without revealing the question or answer.
- **Visuals & Stadium Spotlight:** Philadelphia skyline background header, team logos, and an interactive modal showcasing Lincoln Financial Field ("The Linc").
- **Streak & Stats Tracking:** Tracks played count, win percentage, current streak, and max streak via `localStorage`.

## How to Deploy on GitHub Pages
1. Create a public repository on GitHub (e.g., `eagles-daily-trivia`).
2. Upload `index.html` and `README.md` to the root directory of your repository.
3. Go to your repository **Settings** -> **Pages**.
4. Under **Build and deployment**, set the source branch to `main` (or `master`) and `/ (root)`.
5. Click **Save**. Your site will be live within a minute!
